## 硬件配置
- 1. 主控：STM32F401RET6
- 2. 屏幕：SSD1312 Oled 0.96inch IIC接口 128x64分辨率
- 3. 电机驱动：DRV8313
- 4. 电流采样：INA240A2
- 5. 蓝牙通信：KT6368A
- 6. 串口通信：CH340N
- 7. 外壳：3D打印

## 功能

- 目前已经实现小功率无刷电机的位置、角度开闭环控制，适配了电流环的代码，可以正常运行。 
- 支持使用串口进行有线调试或者使用蓝牙进行无线调试。
- 支持3S航模锂电池接入（12.6V / XT60接口）.
- 板载Oled、两颗实体按钮以及蜂鸣器方便于人机交互。
- 引出一路IIC接口和一路SPI接口。
- 引出SWD烧录口，方便使用`ST-Link`or`DAP-Link`进行程序烧录。

## 串口指令集

调试走蓝牙 `KT6368A`（USART6），波特率 **115200 8N1**。每条命令以**换行\r\n**结尾。

> 格式约定：字母命令（`H`/`S`/`E`/`M`/`N`）的第二个字符必须**紧跟、无空格**（如 `EU`、`S1`、`MT`）；带参数的命令，参数紧跟命令字母（如 `T6.28`、`P0.5`）。

### 连接与读取

| 命令 | 功能 | 返回 |
|---|---|---|
| `H` | 链路测试 | `Hello World!` |
| `V` | 读实时速度 | `Velocity=…`（rad/s） |
| `A` | 读绝对角度 | `Angle=…`（rad） |
| `C` | 读电流采样 | `rawA/rawB`、`ia/ib`、`θ`、`Id`、`Iq` |
| `R` | 读环内状态 | `sp`（速度环输出/电流指令）、`Iq`、`Id`、`Vq`、`Vd` |
| `G` | 触发波形采集 | 采 1000 点 @1kHz 后 dump `v,ang,isp,iq,vq`（每行 5 个值） |

### 编码器选择（会失能并重新初始化 FOC）

| 命令 | 编码器 | 极对数 |
|---|---|---|
| `S0` | AS5600（I2C） | 7 |
| `S1` | AS5047P（SPI） | 11 |

### 使能与运行模式

| 命令 | 功能 |
|---|---|
| `EU` | 使能（切速度模式、目标清零） |
| `ED` | 失能（目标清零） |
| `MA` | 角度闭环 |
| `MV` | 速度闭环 |
| `MT` | 力矩闭环 |

### 力矩控制方式

| 命令 | 方式 |
|---|---|
| `NV` | 电压模式（电流开环） |
| `NC` | DC current（电流闭环） |

### 目标值与 PID 参数

| 命令 | 参数 | 单位 |
|---|---|---|
| `T<x>` | 目标值 | 速度=rad/s；角度=rad；力矩=电压模式 V / 电流模式 A |
| `P<x>` | 速度环 P（**设置后自动关闭速度调度**） | — |
| `I<x>` | 速度环 I | — |
| `Q<x>` | 电流环 P | 欧姆 |
| `W<x>` | 电流环 I | 欧姆/秒 |
| `Y<x>` | 速度反馈 LPF 时间常数 Tf（**设置后自动关闭速度调度**） | s |
| `Z<x>` | 电流反馈 LPF 时间常数 Tf | s |
| `B<x>` | 位置环 P | — |
| `L<x>` | 电流限幅，默认 1.5A | A（上限 `MAX_CURRENT_LIMIT` = 3.0A） |
| `K` | 开关"速度环参数调度"（默认 ON） | — |

### 速度环参数调度（默认开启）

实测发现电机在全速度段无法用一组固定增益同时满足"低速不顿挫"和"高速不抖"：
低速靠高增益压住摩擦/齿槽（且反馈滤波要轻），高速则必须降增益并加重反馈滤波，
否则环路会在电流限幅间反复撞击形成**极限环**（实测 +36rad/s 时指令有 15-42% 的时间顶在
限幅上，转矩脉动 iq_std 0.28-0.33A）。

因此 `FOCLoop_task` 里按 `|shaft_velocity|` 在两组参数间线性插值：

| | `|v| <= 15 rad/s` | `|v| >= 25 rad/s` |
|---|---|---|
| 速度环 P | 0.30 | 0.15 |
| 速度反馈 LPF Tf | 0.020 s（≈8Hz） | 0.040 s（≈4Hz） |

实测效果（+36rad/s）：**iq_std 0.275 → 0.076A（−72%），限幅饱和 15% → 0%**；
低速段（0.5-12rad/s）与原来完全一致，无退化。`K` 可临时关闭做对比，`P`/`Y` 手动设值也会
自动关闭调度（回显会提示 `VelSched=OFF`），要恢复自动再发一次 `K`。

### 快速上手

上电默认：AS5047P、失能、DC current 电流闭环、速度闭环。典型流程：

```
S1      # 选 AS5047P（默认已是，可跳过）
EU      # 使能
MV      # 切速度闭环（EU 会把 controller 置为角度闭环，务必补发 MV）
T5      # 设 5 rad/s 转起来
V       # 读速度
ED      # 失能停止
```

> 注意：`EU` / `ED` 都会把 `controller` 置为**角度闭环**并把目标清零（即"使能后先守住当前位置"）。
> 因此使能后必须再发 `MA`/`MV`/`MT` 选择你要的模式。`EU` 的回显文案是历史遗留的
> `PowerUP, VelocityMODE!`，**与实际行为不符**，请以本文档为准。
>
> 另注：固件按 `RX_BUF[0]`+`[1]` 解析前两个字符，`EU MV` 这样写在一条里只会执行 `EU`。

DC current 电流闭环：

```
NC      # 切电流闭环
EU      # 使能
MT      # 力矩模式
T0.1    # 设 0.1A 目标电流
C       # 读电流验证
ED      # 失能
```

> 注意：`EU` 会先把 `controller` 置为角度闭环，所以力矩模式务必按 `EU → MT` 顺序执行。

## 已知问题

- **正反转不对称**：同一转速下正转的转矩脉动比反转大 1.5-2 倍，且用**恒压开环**（`EU → MT → NV → T±V`，
  完全断开所有反馈）复现同样倍数 → 说明来源在被控对象（电机本体/驱动/机械），不在控制环。
  主频随转速线性上升（约 4 次/转）→ 属"位置锁定"的脉动，不是固定频率的结构共振。
  当前用上面的速度调度把控制环对它的放大压掉；**根治需要换速度估计（观测器/陷波）或排查电机本体**。
- **`EU` 回显文案**：`PowerUP, VelocityMODE!` 与实际行为（角度闭环）不符，未改代码以免影响既有脚本。
- **限幅与电机额定**：`L` 的上限已放到 3.0A（= DRV8313 的 OCP 点），此时软件不再留保护余量，
  而 3505 电机额定只有 0.5A。实测正常空载运行电流仅 0.1-0.3A、完全碰不到限幅，
  所以拉高上限只削弱保护、不带来任何收益；建议保持默认 1.5A。
